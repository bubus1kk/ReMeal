# О проекте

**ReMeal** — это настольная информационная система, предназначенная для бронирования и реализации непроданных блюд из кафе, столовых, ресторанов и других предприятий общественного питания.

Проект помогает решить проблему пищевых отходов, предоставляя заведениям возможность реализовывать оставшуюся продукцию по сниженной цене, а пользователям — приобретать качественную еду по выгодной стоимости.

# Модули системы

Система **ReMeal** состоит из 10 функциональных модулей, каждый из которых отвечает за отдельную область бизнес-логики приложения.

---

## Модуль авторизации

Обеспечивает аутентификацию пользователей в системе.

### Функции

* вход в систему;
* проверка учетных данных;
* завершение сеанса пользователя;
* управление текущей сессией;
* контроль доступа к функционалу приложения.

---

## Модуль регистрации

Предназначен для создания новых учетных записей.

### Функции

* регистрация пользователей;
* проверка корректности данных;
* создание профиля пользователя;
* назначение роли при регистрации;
* валидация уникальности учетных записей.

---

## Модуль лотов

Отвечает за управление отдельными предложениями еды.

### Функции

* создание лотов;
* редактирование лотов;
* изменение статуса лота;
* управление количеством доступных позиций;
* просмотр информации о лоте.

---

## Модуль наборов

Предназначен для работы с наборами блюд, формируемыми заведениями.

### Функции

* создание наборов;
* редактирование состава наборов;
* управление стоимостью;
* просмотр информации о наборах;
* публикация доступных предложений.

---

## Модуль бронирования

Реализует процесс резервирования наборов пользователями.

### Функции

* создание бронирования;
* подтверждение бронирования;
* отмена бронирования;
* хранение истории заказов;
* отслеживание статуса бронирований.

---

## Модуль администрирования

Предоставляет инструменты управления платформой.

### Функции

* управление пользователями;
* блокировка и разблокировка аккаунтов;
* просмотр системной статистики;
* контроль работы системы;
* администрирование данных платформы.

---

## Модуль карт

Позволяет отображать заведения на интерактивной карте.

### Функции

* отображение точек питания на карте;
* поиск заведений по местоположению;
* просмотр информации о заведении;
* навигация к выбранной точке;
* визуализация доступных предложений.

---

## Модуль точек питания

Предназначен для управления заведениями общественного питания.

### Функции

* создание точек питания;
* редактирование информации о заведениях;
* управление адресами и контактами;
* привязка наборов и лотов к заведению;
* управление владельцами заведений.

---

## Модуль личного кабинета

Предоставляет пользователю персональное рабочее пространство.

### Функции

* просмотр профиля;
* редактирование персональных данных;
* просмотр истории бронирований;
* управление учетной записью;
* получение персональной информации.

---

## Модуль аналитики

Предназначен для анализа эффективности работы системы и заведений.

### Функции

* анализ продаж;
* построение графиков и диаграмм;
* формирование статистических отчетов;
* анализ популярности наборов;
* расчет прибыли и показателей эффективности.

# Сценарий работы системы

```text
Заведение
    │
    ▼
Создание лота
    │
    ▼
Публикация предложения
    │
    ▼
Пользователь просматривает каталог
    │
    ▼
Выбор набора еды
    │
    ▼
Бронирование
    │
    ▼
Подтверждение заказа
    │
    ▼
Получение заказа
```
